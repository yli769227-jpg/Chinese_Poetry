# 生成样例

本目录收录 A 档模型 (15M 参数, 5000 步训练) 的真实生成结果。

## 文件说明

| 文件 | 内容 |
|------|------|
| [`01_freeform.txt`](01_freeform.txt) | 无 prompt 自由生成 3 个样本，模型自发产出整组系列诗 |
| [`02_dufu_prompted.txt`](02_dufu_prompted.txt) | 给 `《登高》杜甫\n风急天高` 让模型续写，3 个样本 |

## 关键观察

### ✅ 模型学到了什么

1. **作者风格指纹**：宋太宗 → 道教/金丹；释绍昙 → 禅偈；陆游 → 漂泊/秋雨；杜甫 → 边塞/送别
2. **格律格式**：五言/七言、绝句/律诗、词牌、偈颂的不定字数
3. **系列编号**：从训练数据学到了"其一、其二...其一○○" 的连续编号
4. **标题语法**：会编"《和 X 同赏雪》"、"《送 X 归 X》"这种符合古典诗题命名习惯的题目

### ❌ 模型没学到什么

1. **真实性**：所有诗作都是"模型编造"的，连作者归属都是杜撰
2. **严格平仄**：大致接近但不严格对仗
3. **跨句语义连贯**：单句通顺，但上下句意思可能跳跃
4. **罕见字处理**：训练集外的字会出现 `□` / 空方块

### 📚 教学价值

这就是 LLM 工作的本质：**统计模式匹配 + 概率采样**。它不知道自己是在编造还是在回忆 ——
只是在执行"哪个字最符合这个模式"的局部决策。这跟 GPT-4 写代码、写小说、产生幻觉的机制完全相同，
只是规模和数据差几个数量级。

## 复现这些样本

按 [项目根目录 README](../README.md) 的 Quick Start 训练好 A 档模型，然后：

```bash
cd nanoGPT

# 自由生成
python sample.py --out_dir=out/poetry_small \
    --num_samples=3 --max_new_tokens=500 \
    --temperature=0.8 --top_k=200

# 杜甫续写
echo -n '《登高》杜甫
风急天高' > /tmp/prompt.txt
python sample.py --out_dir=out/poetry_small \
    --start=FILE:/tmp/prompt.txt --num_samples=3 \
    --max_new_tokens=200 --temperature=0.8 --top_k=200
```

> 注意：每次采样结果都不同（除非固定 random seed）。模型会输出风格相似但内容不同的诗。
